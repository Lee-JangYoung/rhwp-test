# 양식(템플릿) 제작 가이드

양식은 한글(한컴오피스)에서 만든 HWP/HWPX 파일이며, 변환기는 이를 열어 스타일과 쪽 설정을 그대로 사용한다. 현재 지정 양식은 없으므로 샘플 양식을 먼저 만든다.

## 양식에 포함할 것

| 요소 | 규칙 |
|---|---|
| 쪽 설정 | 용지, 여백, 머리말/꼬리말, 쪽번호는 양식에서 정의 |
| 스타일 | `style-map.yaml`의 `styles` 값과 **이름이 정확히 일치**해야 함 |
| 표지 | 값이 바뀌는 곳은 **누름틀(필드)** 로 만들고 이름을 `fields` 값과 일치시킴 |
| 본문 시작 위치 | 책갈피 `본문시작` 지정(권장) |
| 표 스타일 | 머리행/내용 셀 서식을 양식에 정의 [검증 필요] |
| 번호/글머리표 | 양식에 번호 매기기 정의 포함 [검증 필요] |

## 권장 스타일 목록 (샘플 양식 기준)

`개요 1~4`, `바탕글`, `글머리표 1~3`, `번호 1~3`, `인용`, `코드`, `캡션`, `표머리`, `표내용`

## 점검 절차
1. 양식을 한글에서 저장한다(HWP 또는 HWPX).
2. `md2hwp inspect templates/x.hwpx`로 스타일·필드·책갈피 목록을 출력한다(CLI에 구현).
3. 출력 목록과 `style-map.yaml`을 대조한다.
4. 샘플 md로 변환해 쪽수와 스타일 적용을 확인한다.

## 주의
- 양식에 본문 내용이 이미 있으면 `contentStart` 이후에 삽입하고, 기존 내용은 보존한다.
- 개인정보·내부 정보가 있는 양식을 저장소에 커밋하지 않는다. 공개 가능한 샘플만 `templates/`에 둔다.
- 양식 파일 변경은 회귀 테스트(골든)를 함께 갱신한다.
