# 테스트 전략

## 계층

| 계층 | 대상 | 방법 | rhwp 필요 |
|---|---|---|---|
| 단위 | 파서, IR 변환, style-map 해석, 렌더 계획 | Vitest, 입력/기대 JSON | X |
| 어댑터 | 각 `HwpWriter` 메서드 | 실제 WASM 로드, 편집 → 저장 → 재로드 왕복 | O |
| 통합 | md → 파일 전체 | 예제 md를 변환하고 골든과 비교 | O |
| 시각 | 페이지 렌더 | SVG 스냅샷(허용 오차), 사람 검토 | O |
| 호환 | 한컴 열림 | 수동 체크리스트(릴리스 전) | - |

## 골든 비교 항목
바이트 동일 비교는 취약하므로 정규화된 지표로 비교한다.

| 지표 | 확인 방법 |
|---|---|
| 쪽수 | `pageCount()` |
| 텍스트 | `getPageText(n)`을 이어 붙여 비교 |
| 스타일 적용 | 문단별 스타일 이름 목록 (`getStyleAt` 등) [검증 필요] |
| 표 구조 | 행/열 수, 셀 텍스트 |
| 필드 값 | `getFieldValueByName` |
| 저장 손실 | `contentLoss()` 또는 WithReport 결과 |
| 재로드 | `exportHwpVerify()` 결과 |

## 예제 세트 (`examples/`)
1. `basic.md`: 제목 1~4, 문단, 강조
2. `lists.md`: 중첩 목록, 번호 재시작
3. `tables.md`: 정렬, 긴 셀, 큰 표(쪽 넘김)
4. `images.md`: 큰 이미지, 작은 이미지, 캡션
5. `diagrams.md`: Mermaid 유형별
6. `full-report.md`: front-matter + 전체 요소 + 각주
7. `edge.md`: 빈 문서, 매우 긴 문단, 이모지/한자/옛한글, 미지원 HTML

## 비기능 테스트
- 결정성: 동일 입력 두 번 변환한 결과의 정규화 지표 일치(NFR-01)
- 성능: 100쪽 분량 md 변환 시간 측정(NFR-06)
- 보안: 경로 탈출(`../../`) 이미지, 거대 이미지, 악성 SVG 입력(NFR-04)

## CI
- PR마다 단위·어댑터·통합 테스트
- Mermaid 렌더는 Chromium이 있는 잡에서만 실행
- rhwp 버전 상향은 별도 PR로 하고 골든 변화를 리뷰한다
