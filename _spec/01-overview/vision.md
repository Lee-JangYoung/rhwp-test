# 비전과 범위

## 목적
LLM이 Markdown으로 작성한 **SI 산출물**을 **등록한 양식**에 맞춰 **HWPX**로 자동 변환한다(기준 출력 HWPX, HWP 5.0도 지원). 한컴오피스 설치 없이 동작하고, 한컴에서 열었을 때 양식과 거의 동일해야 한다(검증 기준은 미정).

**Markdown이 원본이고 산출물 파일은 생성물이다.** 수정은 md에서 하고 다시 생성한다(한글에서 고친 내용을 md로 되돌리지 않는 정책은 확정 전).

## 대상 산출물
유스케이스 명세서, 클래스 명세서, 데이터베이스 명세서(테이블). "항목 1건 = 블록이 반복되는 표 중심 문서"다.

## 사용자
AI 에이전트(md 작성·검증·변환 호출: MCP/CLI), 개발자/CI(CLI), 문서 작성자(웹 UI, 후순위).

## 범위
- Markdown 입력: 문서 유형별 템플릿·규약·검증, 위반은 LLM에 되돌려 수정
- **HWPX 출력** (양식 파일 기반), front-matter를 표지 필드(누름틀)에 채움. **HWP 5.0**은 같은 세션에서 함께 저장(`--format hwpx,hwp`)
- ```` ```mermaid ```` 블록을 이미지로 렌더해 삽입
- 양식 등록(분석 → 프로필; LLM 초안은 `author`), 변환 검증 리포트(손실, 쪽수, 경고)
- 공통 코어 + CLI + MCP + 웹 UI, 엔진은 인터페이스로 분리해 교체 가능
- **계획(승인 대기)**: ERD PNG, DOCX·XLSX·PPTX 출력 — [ADR-0019](../adr/0019-multi-format-output.md)

## 후순위·범위 밖
양식 기반 Office 출력, Google 출력, 서버(다수 사용자), 양식 자동 도출, HWP → md 역변환, 한컴과 픽셀 단위 동일 보장, rhwp 자체 개선. 상세 메모는 [roadmap.md](../roadmap.md).

## 성공 기준
1. 샘플 md가 등록 양식 스타일대로 HWPX로 저장되고 rhwp 재로드와 한컴에서 열린다.
2. 새 양식은 프로필 작성(재등록)과 짧은 보정만으로 추가된다.
3. 같은 입력은 같은 결과이며(변환에 LLM 불사용) 회귀 테스트가 돈다.

## 용어
| 용어 | 뜻 |
|---|---|
| HWP / HWPX | 한글 5.0 바이너리 / ZIP+XML 기반 개방형 포맷(KS X 6101). 기준 출력은 HWPX([ADR-0010](../adr/0010-hwpx-first-output.md)), HWP 5.0은 파생([ADR-0019](../adr/0019-multi-format-output.md)) |
| 양식(템플릿) | 스타일·쪽 설정·머리말·표지가 정의된 HWPX 파일 |
| 프로필 | 문서 유형 하나의 변환 정의(양식 + md 읽기 규칙 + 규약 + 바인딩) |
| 누름틀(필드) | 값을 채울 수 있는 위치 |
| 데이터 트리 | 프로필의 읽기 규칙으로 md에서 만든 JSON([data-model.md](../02-architecture/data-model.md)) |
| 엔진 | 문서를 열고 편집·저장하는 라이브러리 구현체(첫 구현체는 rhwp) |
