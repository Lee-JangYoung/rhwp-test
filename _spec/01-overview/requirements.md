## 비기능 요구사항

| ID | 요구사항 | 기준 |
|---|---|---|
| NFR-01 | 결정성: 동일 입력·옵션이면 동일 출력 | 바이트 동일 또는 정규화 후 동일 [검증 필요] |
| NFR-02 | 환경 독립: 코어는 Node와 브라우저에서 동일 코드로 동작 | ADR-0003 |
| NFR-03 | 호환성: 산출물이 rhwp 재로드와 한컴 뷰어에서 열림 | 수동 확인 절차 포함 |
| NFR-04 | 안전성: 입력 md의 이미지/링크 경로 검증(경로 탈출 방지), 크기 한도 | |
| NFR-05 | 유지보수: rhwp 호출은 어댑터 한 곳에서만 | ADR-0005 |
| NFR-06 | 성능: 100쪽 분량 md를 CLI에서 합리적 시간(목표 30초 이내)에 변환 | 측정 후 조정 |
| NFR-07 | 오프라인: 변환에 외부 네트워크가 필요 없다 | 웹 `@rhwp/editor` 기본 URL은 예외 |
| NFR-08 | 라이선스: 의존성은 MIT/Apache 등 허용 라이선스만 | |
