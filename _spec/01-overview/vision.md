# 비전과 범위

## 목적
Markdown으로 쓴 산출물을 **지정 양식의 스타일에 맞춰 HWP/HWPX로 자동 변환**한다. 한컴오피스 설치 없이 동작한다.

## 사용자
작성자(웹 UI), 개발자/CI(CLI), AI 에이전트(CLI 호출).

## 범위
- Markdown 확장형 입력: 제목, 문단, 강조, 목록, 표, 이미지, 인용, 코드블록, 각주, 수식, 쪽 나눔
- Mermaid 등 다이어그램을 이미지로 삽입
- HWP 5.0 / HWPX 출력 선택
- 양식 파일 기반 스타일 적용, front-matter를 표지 필드(누름틀)에 채움
- 변환 검증 리포트(손실, 쪽수, 경고)
- 공통 코어 + CLI + 웹 UI

## 범위 밖
HWP → Markdown 역변환, 한컴과 픽셀 단위 동일한 조판 보장, 협업 편집/서버 저장소, rhwp 자체 개선.

## 성공 기준
1. 샘플 md가 샘플 양식 스타일대로 HWP/HWPX로 저장된다.
2. 산출물이 rhwp 재로드와 한컴 뷰어에서 열린다.
3. 양식 교체는 템플릿 파일과 `style-map.yaml` 교체만으로 된다.
4. 같은 입력은 같은 결과이며 회귀 테스트가 CI에서 돈다.

## 용어
| 용어 | 뜻 |
|---|---|
| HWP / HWPX | 한글 5.0 바이너리 / ZIP+XML 기반 개방형 포맷 |
| 양식(템플릿) | 스타일·쪽 설정·머리말·표지가 정의된 HWP/HWPX 파일 |
| 누름틀(필드) | 값을 채울 수 있는 위치 |
| IR | 변환기 내부 중간표현 |
| 어댑터 | rhwp 호출을 모아 둔 계층 |
