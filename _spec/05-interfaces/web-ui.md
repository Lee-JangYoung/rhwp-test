# 웹 UI (가설)

역할: **등록된 프로필로 변환·미리보기·다운로드**. 양식 등록의 LLM 보강은 MCP/CLI 쪽에서 하고 웹은 LLM을 쓰지 않는다. 변환은 **브라우저 안에서** 수행한다(문서를 서버로 보내지 않음).

## 범위

| 단계 | 기능 |
|---|---|
| **MVP** | 문서 유형(프로필) 선택 → md 업로드/붙여넣기 → **규약 검사 결과 표시** → 변환 → 쪽 미리보기(SVG) → 경고 리포트 → HWP/HWPX 다운로드 |
| 2단계 | front-matter 입력 폼, `template.md`·`prompt.md` 다운로드/복사, 프로필 가져오기(폴더/zip) |
| 3단계(필요 시) | 일괄 변환, 변환 이력 |
| 제외 | md WYSIWYG 편집, 계정/서버 저장, 협업, 양식 편집기, `@rhwp/editor` 임베드(후속 검토) |

md는 AI가 만들므로 편집기는 텍스트 영역이면 충분하다. 수정은 AI에게 재요청하거나 한글에서 한다.

## 기술 사항
- Vite 번들, `rhwp_bg.wasm`은 정적 자산, `measureTextWidth`는 Canvas 2D.
- 큰 문서는 Web Worker에서 변환 — `OffscreenCanvas`에서 폭 측정이 되는지 확인 필요 [검증 필요 S-13].
- 미리보기 SVG는 sanitize 후 DOM에 넣고(`innerHTML` 직접 삽입 금지) 업로드 크기 상한을 둔다. 원시 HTML은 삽입하지 않는다.
- 프로필은 번들에 포함하거나 사용자가 가져온다. 개인정보가 있는 양식·문서는 저장하지 않는다.
