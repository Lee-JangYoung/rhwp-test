# ADR-0002: 양식 파일 + style-map으로 스타일링

- 상태: 제안 (스파이크 S-01, S-03 결과로 확정). 양식 등록과 프로필 구조는 [ADR-0006](0006-template-registration-and-doctype-profile.md)이 보완하며, `style-map.yaml`은 프로필의 `profile.yaml`로 이어진다.
- 날짜: 2026-10-14

## 배경
양식은 기관/프로젝트별로 다르고 자주 바뀐다. 스타일, 쪽 설정, 머리말, 표지를 코드로 재현하는 것은 비용이 크고 한컴과의 차이가 생긴다. `createEmpty()`로 만든 빈 문서는 스타일 목록이 비어 있다(`createBlankDocument()`는 미검증).

## 결정
양식은 한글에서 만든 HWP/HWPX **템플릿 파일**을 그대로 열어 사용하고, Markdown 요소와 양식 스타일의 연결은 `style-map.yaml`로 선언한다. 스타일 이름이 양식에 있는지 변환 시작 시 검증한다.

## 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| 코드에서 스타일 직접 생성 | 양식 파일 불필요 | 양식 재현 어려움, 유지보수 부담 |
| 양식 파일 + 자리표시자 치환만 | 단순 | 가변 길이 본문(표, 목록) 처리 불가 |

## 결과
- 양식 교체가 파일·설정 교체만으로 가능하다.
- 스파이크에서 `applyStyle`이 기대대로 동작하지 않으면 직접 서식 적용으로 대체하고 본 ADR을 갱신한다.
