# ADR-0012: 반복 블록은 양식 표를 복제하고 라벨로 셀을 채운다

- 상태: 채택 (rhwp 내 PoC 확인, 한컴 확인 전 — [S-23](../06-quality/verification-spike.md))
- 날짜: 2026-10-15

## 배경
문서 1건에 항목이 N개(유스케이스 등)이고 항목마다 같은 표가 반복된다. 채움형(양식 블록 복제)과 생성형(표를 코드로 생성)이 후보였고([doctype-profile.md](../04-conversion/doctype-profile.md)), R-02에서 복제본별 값 채움이 미해결이었다.

## 결정
**채움형**으로 한다.
1. 양식의 첫 표를 원형으로 `copyControl` → `insertParagraph` → `pasteControl`로 N−1회 복제한다.
2. 표의 0열 텍스트를 **라벨**, 같은 행의 1열을 **값 셀**로 찾는다(병합 셀 포함).
3. 값 셀은 셀 주소로 지정해 채운다: 셀 안 문단 병합 → 기존 글 삭제 → 줄마다 문단 분할 + 삽입. 값이 없는 라벨은 안내 문구를 비운다.
4. 복제한 표는 떠 있는 표 + `pageBreak`=CELL로 두고, 채운 뒤 셀 높이를 렌더 높이로 맞춘다(L-14, L-15).
5. 다이어그램은 표 뒤 문단에 "글자처럼 취급" 그림으로 넣고, 뒤쪽 블록부터 삽입해 앞쪽 문단 번호가 밀리지 않게 한다.
6. 저장 후 재로드해 값·표 수·그림 배치·쪽 나눔·표 높이·컨트롤 개수를 검증한다.

`importParagraphBlock`은 셀 내부 구조가 있는 블록에서 18/26만 성공해 쓰지 않는다. `replaceOne`은 표 셀에서 동작하지 않는다.

## 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| 생성형(표를 코드로 생성) | 양식 의존이 적음 | 양식의 병합·테두리·스타일 재현이 어려움(미검증) |
| `importParagraphBlock` | 문단 단위 복제 | 셀 내부 구조에서 실패 |
| 고유 필드명 치환 | 단순 | 표 셀에서 `replaceOne` 불가 |

## 결과
- 양식의 시각 요소는 양식 파일이 가지고, 프로필은 라벨 매핑과 동작만 정한다([ADR-0002](0002-template-file-based-styling.md)).
- 라벨 규칙(0열=라벨, 1열=값)은 첫 규칙이며, 다른 표 구조는 프로필로 지정해야 한다(미정).
- 하드코딩(필드·라벨 이름)은 프로필 설정으로 옮긴다(구현 2단계).
