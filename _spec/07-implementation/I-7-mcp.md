# I-7 MCP 서버

상태: **권장안으로 구현 완료**(개발자 지시: 계획된 기능을 먼저 끝까지 개발하고 평가 후 재설계). 선행: [I-4](I-4-cli.md)(D12: 작성 도구는 I-4 직후, 변환 도구는 I-7 — 한 번에 구현). 명세: [mcp.md](../05-interfaces/mcp.md).

## 결정 사항 (권장안)
| # | 결정 | 근거 |
|---|---|---|
| D1 | 공식 SDK `@modelcontextprotocol/sdk` 1.32.1(MIT) + `zod` 4.6.7, stdio 전송만 | 표준, LLM 클라이언트 대부분 지원. 원격(HTTP)은 후순위 |
| D2 | 작성 도구와 변환 도구를 한 서버에 둔다(`yangsik-mcp`) | 같은 코어 함수, 에이전트가 한 서버로 등록→변환 |
| D3 | 파일 접근은 `--root` 허용 폴더로 제한(경로 탈출·심볼릭 링크 차단) | 에이전트가 임의 파일을 읽고 쓰지 못하게 |
| D4 | 서버는 LLM을 부르지 않는다. md 위반·프로필 오류는 에러가 아니라 **구조화 결과**로 돌려줘 호스트 LLM이 고치게 한다 | ADR-0007, 수정 루프 |
| D5 | 실행은 CLI와 같이 `tsx` 등록 스크립트(빌드 없음) | 배포 형태는 기능 평가 후 |

## 구현 결과
- `packages/mcp`: `src/server.ts`(도구 12개), `src/paths.ts`(PathGuard), `src/main.ts`(stdio 진입), `bin/yangsik-mcp.mjs`.
- 시험 11개: 도구 목록, 코어와 같은 결과(분석·kinds·guide·schema), 점검(틀린 초안 → 코드·후보), 드라이런, 대조표, 문서 유형 목록·md 지침, 검증 루프(위반 줄 번호 → 통과), md 본문 변환·저장·미리보기, 클래스 명세서 변환, 허용 폴더 밖 읽기·쓰기·경로 탈출·없는 파일 거부, 상대 경로, 실제 stdio 프로세스 호출(SDK 클라이언트), LLM 의존 없음.
- **미검증**: 실제 MCP 클라이언트(Claude Desktop·Claude Code 등)에서의 연동(이 환경에서는 SDK 클라이언트로만 시험), 큰 md·긴 변환에서의 시간 제한, Mermaid 렌더(Chromium 없으면 자동 생략하고 `mermaid:false`로 알림).
