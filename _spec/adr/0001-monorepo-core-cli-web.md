# ADR-0001: 공통 코어 + CLI + 웹의 모노레포 구성

- 상태: 제안
- 날짜: 2026-10-14

## 배경
CLI(배치/CI/에이전트)와 웹 UI(작성자)를 모두 제공해야 한다. 두 접점이 변환 로직을 따로 구현하면 결과가 어긋난다.

## 결정
`packages/core`(변환 로직), `packages/cli`, `packages/web`을 하나의 pnpm workspace 모노레포로 구성하고, 변환 로직은 `core`에만 둔다.

## 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| CLI만 | 단순 | 비개발자 사용 어려움 |
| 웹만 | 접근성 | 배치/CI 불가 |
| 별도 저장소 | 독립 배포 | 코어 동기화 비용 |

## 결과
- 동일 코어로 두 접점의 결과가 일치한다.
- 코어는 환경 독립이어야 한다([ADR-0003](0003-environment-agnostic-core.md)).
