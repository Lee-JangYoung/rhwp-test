# 비전과 범위

## 목적
AI(LLM)가 생성한 **SI 산출물 Markdown**을 **등록한 양식**에 맞춰, **한컴에서 열었을 때 거의 동일한** HWP/HWPX로 자동 변환한다. 한컴오피스 설치 없이 동작한다.

핵심 아이디어: 양식 샘플을 등록하면 md 양식(템플릿·스키마)이 만들어지고, AI가 그 md 양식대로 작성한 문서를 같은 양식의 HWP로 변환한다([doctype-profile.md](../04-conversion/doctype-profile.md)).

## 대상 산출물
유스케이스 명세서, 클래스 명세서, 데이터베이스 명세서(테이블). 모두 "항목 1건 = 블록이 반복되는 표 중심 문서"다. 이후 다른 SI 산출물로 확장한다.

## 사용자
- AI 에이전트: md 작성, 규약 검증, 변환 호출(MCP/CLI)
- 개발자/CI: CLI 배치 변환
- 문서 작성자: 웹 UI에서 변환·미리보기·다운로드

## 우선 기능 (사용자 지정 순서 반영)
1. md → HWP/HWPX 변환
2. 표지/필드 자동 채움
3. Mermaid 등 다이어그램 이미지 삽입
4. 웹 UI

## 범위
- Markdown 입력: 제목, 문단, 강조, 목록, 표, 이미지, 인용, 코드블록, 각주, 수식, 쪽 나눔
- 양식 등록(분석 → 프로필 초안 → 사람 승인)과 md 규약 검증
- HWP 5.0 / HWPX 출력 선택, 변환 검증 리포트(손실, 쪽수, 경고)
- 공통 코어 + CLI + MCP + 웹 UI

## 범위 밖
HWP → Markdown 역변환, 한컴과 픽셀 단위 동일한 조판 보장, 협업 편집, rhwp 자체 개선.

## 성공 기준
1. 샘플 md가 등록 양식 스타일대로 HWP/HWPX로 저장되고 rhwp 재로드와 한컴 뷰어에서 열린다.
2. 새 양식은 등록(재등록)과 짧은 보정만으로 추가된다.
3. 같은 입력은 같은 결과이며(변환에 LLM 불사용) 회귀 테스트가 CI에서 돈다.

## 미결
- "한컴과 거의 동일"의 검증 가능한 기준(쪽수 일치, 표 깨짐 없음, 머리말·표지 일치, 줄바꿈까지)
- 실제 양식 확보, 프로필 저장·관리 방식, 다중 사용자(서버) 제공 방식

## 용어
| 용어 | 뜻 |
|---|---|
| HWP / HWPX | 한글 5.0 바이너리 / ZIP+XML 기반 개방형 포맷 |
| 양식(템플릿) | 스타일·쪽 설정·머리말·표지가 정의된 HWP/HWPX 파일 |
| 프로필 | 문서 유형 하나의 변환 정의(양식 + md 템플릿 + 스키마 + 매핑) |
| 누름틀(필드) | 값을 채울 수 있는 위치 |
| IR | 변환기 내부 중간표현 |
| 어댑터 | 코어 위의 인터페이스(CLI/MCP/웹) 또는 rhwp 호출 계층 |
