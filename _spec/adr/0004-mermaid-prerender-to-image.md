# ADR-0004: Mermaid는 이미지로 사전 렌더링해 삽입

- 상태: 제안 (스파이크 S-04 결과로 포맷 확정)
- 날짜: 2026-10-14

## 배경
HWP에는 Mermaid에 해당하는 개념이 없다. 다이어그램을 한글 도형으로 변환하는 것은 복잡하고 충실도가 낮다.

## 결정
Mermaid 블록을 PNG(가능하면 SVG)로 렌더링해 일반 그림으로 삽입한다. CLI는 `mermaid-cli`, 웹은 브라우저 내 렌더를 사용한다. 렌더 실패 시 원문 코드블록으로 대체하고 경고한다.

## 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| 한글 도형으로 변환 | 편집 가능 | 구현 난이도 매우 높음 |
| 서버 렌더 서비스 호출 | 구현 쉬움 | 외부 전송, 오프라인 불가(NFR-07 위반) |

## 결과
- CLI 실행 환경에 Chromium이 필요하다.
- 삽입된 다이어그램은 한글에서 편집할 수 없다(원본 Mermaid는 md에 남는다).
