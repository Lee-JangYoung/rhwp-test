# ADR-0010: 1차 출력 포맷은 HWPX

- 상태: 제안
- 날짜: 2026-10-14

## 배경
HWP 5.0은 CFB 위의 바이너리 레코드, HWPX는 ZIP+XML(KS X 6101)이다. 공공 문서 유통에서 hwpx 전환이 진행 중이다(2026-04-24 보도: 온나라시스템 hwpx 의무화 확대, 공직자통합메일 hwp 첨부 제한 예정). rhwp 0.8.7은 두 포맷을 모두 저장·재로드·재저장·교차 저장했고(단순 문서, 손실 0건) 검증 비용은 포맷 수에 비례한다.

## 결정
출력은 **HWPX를 1차**로 하고 양식 샘플도 HWPX로 받는다. HWP 5.0 출력은 후순위(엔진 `export('hwp')`는 열어 두되 검증하지 않음).

## 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| HWP 5.0 우선 | 구버전 한글 호환 가능성 | 바이너리라 검증·디버깅·비교가 어렵고 정책 방향과 반대 |
| 둘 다 동시 지원 | 선택 폭 | 검증 부담 2배 |

## 결과
- 골든 비교, 디버깅, 필요 시 XML 패치 엔진 추가가 쉬워진다.
- **제출처가 HWP 5.0만 받는 경우**와 구버전 한글 호환은 확인하지 못했다(한글 2014 이전의 HWPX 지원 정보를 찾지 못함).
- HWPX의 비표준 파일(`META-INF/rhwp-hwp5-origin`)이 한컴에서 문제없는지 S-02로 확인한다.
