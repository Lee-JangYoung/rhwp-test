# 비전과 범위

## 목적
Markdown으로 작성한 산출물을 **지정된 양식(템플릿)의 스타일에 맞춰 HWP/HWPX 파일로 자동 변환**한다. 변환 엔진은 오픈소스 [rhwp](https://github.com/edwardkim/rhwp)(Rust + WASM)를 사용하며, 한컴오피스 설치 없이 동작해야 한다.

## 해결하려는 문제
- 산출물을 Markdown(버전관리, 협업, AI 생성)으로 쓰고 제출은 HWP로 해야 한다.
- 수작업 복사·서식 맞춤은 오류가 잦고 반복 비용이 크다.
- 양식은 기관/프로젝트마다 다르므로 코드 수정 없이 양식을 교체할 수 있어야 한다.

## 사용자
| 사용자 | 사용 방식 |
|---|---|
| 문서 작성자 | 웹 UI에서 md 업로드 → 양식 선택 → 다운로드 |
| 개발자/CI | CLI로 일괄 변환, 파이프라인에 통합 |
| AI 에이전트 | CLI 호출(향후 MCP 도구화 검토) |

## 범위 (In scope)
- Markdown 확장형 입력: 제목, 문단, 강조, 목록, 표, 이미지, 인용, 코드블록, 각주, 수식, 쪽 나눔
- Mermaid 등 다이어그램을 이미지로 변환해 삽입
- HWP 5.0과 HWPX 두 포맷으로 출력 (옵션)
- 양식 파일 기반 스타일 적용, front-matter 메타데이터를 표지 필드에 채움
- 변환 결과 검증 리포트(손실 여부, 쪽수, 경고)
- 공통 코어 + CLI + 웹 UI

## 비범위 (Out of scope)
- HWP → Markdown 역변환
- 한컴오피스와 픽셀 단위로 동일한 조판 보장
- 문서 협업 편집, 서버 저장소
- rhwp 자체의 기능 개선(필요 시 업스트림 이슈로 제기)

## 성공 기준
1. 샘플 Markdown이 샘플 양식의 스타일대로 변환되어 HWP/HWPX로 저장된다.
2. 저장된 파일이 rhwp 재로드와 한컴 뷰어 양쪽에서 열린다.
3. 양식 교체가 `style-map.yaml`과 템플릿 파일 교체만으로 가능하다.
4. 동일 입력은 동일 출력(결정적)이며, 회귀 테스트가 CI에서 돈다.
