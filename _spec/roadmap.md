# 로드맵

| 단계 | 내용 | 산출물 | 완료 기준 | 상태 |
|---|---|---|---|---|
| 0 | 양식 확보 | `templates/` 샘플 양식 | 스타일/필드 목록 확인 | 대기 (양식 없음) |
| 1 | 검증 스파이크 | `spike/`, 검증표 갱신 | S-01~S-14 판정 | 대기 (S-00 완료) |
| 2 | 코어 MVP | `packages/core` | 제목·문단·목록·표·이미지·필드 변환 | 대기 |
| 3 | CLI | `packages/cli` | convert/inspect/validate, 리포트 | 대기 |
| 4 | 확장 요소 | 각주, 코드, 수식, 목차, 쪽 나눔 | 예제 세트 통과 | 대기 |
| 5 | Mermaid | 렌더러 + 삽입 | diagrams 예제 통과 | 대기 |
| 6 | 웹 UI | `packages/web` | 업로드→변환→미리보기→다운로드 | 대기 |
| 7 | 품질 | 골든 테스트, CI | CI 통과, 수동 호환 체크 | 대기 |

## 의존 관계
```
0 ─▶ 1 ─▶ 2 ─▶ 3 ─▶ 4 ─▶ 5
              └────────▶ 6 ─▶ 7
```
- 2단계는 1단계 판정에 따라 매핑 방식(스타일 vs 직접 서식)이 달라질 수 있다.
- 6단계는 코어가 안정된 후 3단계와 병행할 수 있다.

## 미결 사항
- 지정 양식 제공 여부와 형식 (HWP/HWPX/규정 문서)
- 한컴 호환 확인 방법(담당자, 환경)
- 웹 UI 호스팅 방식(정적 호스팅 여부, 폐쇄망 여부)
- 수식 처리 방식(HWP 수식 vs 이미지)
