# ADR-0006: 양식 등록형 문서 유형 프로필

- 상태: 제안 ([ADR-0002](0002-template-file-based-styling.md)를 보완)
- 날짜: 2026-10-14

## 배경
대상은 SI 산출물(유스케이스·클래스·DB 명세서)이고, 결과는 한컴에서 열었을 때 양식과 거의 같아야 한다. md 규약을 우리가 먼저 설계하면 실제 양식과 어긋날 수 있다. 양식은 기관/프로젝트마다 다르고 자주 바뀐다.

## 결정
양식 샘플(HWP/HWPX)을 **등록**하면 그 구조(표, 병합, 머리행, 필드, 스타일)를 분석해 **md 템플릿·스키마·매핑(프로필)** 초안을 만들고, 사람이 승인해 저장한다. 변환은 프로필만 보고 수행한다. 프로필은 파일 묶음으로 git에 둔다([doctype-profile.md](../04-conversion/doctype-profile.md)).

## 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| md 규약을 우리가 먼저 설계(정방향) | 단순 | 양식과 불일치 가능, 양식마다 설계 필요 |
| 양식에서 전부 자동 추론 | 사람 개입 없음 | 양식만으로는 의미(반복 단위·필수·타입)를 알 수 없어 오류 위험 |

## 결과
- 1차는 **사람이 프로필을 작성하고 분석 도구가 보조**한다. LLM 해석을 이용한 자동 초안은 후순위다.
- 양식 교체 = 재등록 + 변경분 보정. 양식 불일치가 줄어든다.
- 양식 확보가 선행 조건이 된다. 양식이 없는 동안은 정방향으로 임시 시작한다.
- 분석 정확도와 반복 블록 처리는 R-01~R-03으로 검증한다.
