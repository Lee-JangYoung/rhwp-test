# ADR-0014: 웹 UI는 React + MUI, 문서 표시는 @rhwp/editor

- 상태: 제안 (웹 UI는 후순위, PoC 화면은 MUI 미적용)
- 날짜: 2026-10-15

## 배경
웹 PoC는 React 19와 `@rhwp/editor`(iframe)로 변환·매핑·미리보기가 동작함을 확인했다([S-18](../06-quality/verification-spike.md)). UI 디자인 라이브러리는 사용자가 MUI로 정했다.

## 결정
- UI: **React + MUI(Material UI, MIT)**. 구현 시 최신 안정 버전을 확인해 정확히 고정한다(2026-10-15 npm 최신 `@mui/material` 9.5.0, React 17~19 지원, 스타일은 `@emotion`).
- 양식·결과 표시는 `@rhwp/editor`를 iframe으로 임베드하고, 매핑·규약 위반·변환 보고는 MUI 패널로 표시한다(iframe은 셀 단위 강조가 불가, L-18).
- 변환은 브라우저 안에서 수행해 문서를 서버로 보내지 않는다. 단 에디터는 외부 호스팅 스튜디오를 쓰므로 문서가 그 페이지에서 처리된다(L-08). 자체 호스팅 여부는 미결.

## 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| 현재 PoC처럼 스타일 없이 | 단순 | 제품 화면으로 부족 |
| 자체 디자인 | 자유 | 개발·유지 비용 |

## 결과
- MUI는 에디터 영역과 변환 코어에 영향이 없고, 번들 크기 영향은 측정하지 못했다 [검증 필요].
- PoC 화면의 MUI 적용은 웹 UI 단계에서 한다.
